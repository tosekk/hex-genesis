# Terraform (game jam build)

A deterministic hex-board terraforming game built with TypeScript, Three.js, and Vite. The design lives in `GAME_DESIGN.md`, and team/agent rules live in `AGENTS.md` and `tasks/`.

```bash
npm install
npm run dev        # http://localhost:5173 (?seed=123 for a fixed seed)
npm test
npm run typecheck
npm run build
```
